# TopoKit Project

This is a TopoKit project generated with the `rag-system` template.

## Project Structure

- `nodes.yaml` - Node definitions
- `edges.yaml` - Edge policies and connections
- `guardrails.yaml` - Safety and determinism controls
- `contracts/` - JSON Schema contracts for data exchange
- `eval/` - Evaluation test cases

## Commands

- `topokit-cli lint` - Validate topology configuration
- `topokit-cli graph` - Generate topology visualization
- `topokit-cli eval` - Run evaluation tests
- `topokit-cli monitor` - Monitor topology execution

## Next Steps

1. Review and customize the generated configuration
2. Add your specific business logic to the contracts
3. Create evaluation test cases in the `eval/` directory
4. Deploy and monitor your topology

For more information, visit https://docs.topokit.dev
